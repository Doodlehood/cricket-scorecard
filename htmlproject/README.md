# Cricket Scorecard

A responsive cricket scorecard UI built with pure HTML & CSS — demonstrates CSS custom properties (variables), Flexbox layout, and card-based UI design.

## Skills Demonstrated

- **CSS Custom Properties** — themeable color palette defined via `:root` variables (primary, secondary, highlight, text, border)
- **Flexbox layout** — centered, responsive page structure
- **Card-based UI design** — elevated container with box-shadow, rounded corners, and controlled max-width for readability across screen sizes
- **Semantic HTML structure** — organized header/content sections within the scorecard

## Overview

The page renders a cricket match scorecard inside a styled card container, with a defined color theme and clean visual hierarchy separating the header from the match details.

## Tech Stack

- HTML5
- CSS3 (custom properties, Flexbox)

## Setup

No build step required — just open `cricket-scorecard.html` in any modern browser.

```bash
# from the project folder
start cricket-scorecard.html   # Windows
open cricket-scorecard.html    # macOS
```
